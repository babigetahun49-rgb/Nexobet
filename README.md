# NEXOBET Web — Starter

A responsive black-and-gold Next.js game-lobby frontend for the NEXOBET concept.

## Included
- Premium dark / gold landing page
- Responsive navigation
- Search and category filters
- 20 original game concept cards
- Demo-mode messaging (no real-money wagering)
- Placeholder interactions for future game demos

## Requirements
- Node.js 18.17 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Build
```bash
npm run build
npm start
```

## Deploy
Push the project to GitHub and import the repository into Vercel, or deploy the Next.js app to a Node.js VPS.

## Important
This is a frontend prototype only. It does not include real-money deposits, withdrawals, wagering, player wallets, or gambling outcome services. Before any real-money product is offered, obtain legal advice on the target jurisdiction, required licences, game certification, age/identity controls, responsible-play controls, and payment-provider approval.
